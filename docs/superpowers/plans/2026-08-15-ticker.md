# Ticker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a web app at `ticker.{domain}` that lists overdue Donetick chores and lets each one be marked done with a single tap.

**Architecture:** A React + Vite SPA served by nginx. The same nginx reverse-proxies `/api/*` to the Donetick service over the Swarm overlay network, injecting the Donetick API key as a `secretkey` request header so the key never reaches the browser. Deployed as a one-service Docker Swarm stack by a new Ansible role, behind Traefik with `traefik-internal` + `traefik-forward-auth`.

**Tech Stack:** React 19, TypeScript, Vite, Vitest + React Testing Library, plain CSS, nginx, Docker Swarm, Ansible.

**Spec:** `docs/superpowers/specs/2026-08-15-ticker-design.md`

## Global Constraints

- **Node base image:** `node:24.14-trixie@sha256:81649592d9833d9220423561fc517b34e932b751873274024c2a969ff4a9bfc2` (same digest as `roles/planner/Dockerfile`).
- **nginx base image:** `nginx:1.29.5@sha256:341bf0f3ce6c5277d6002cf6e1fb0319fa4252add24ab6a0e262e0056d313208` (same digest as `roles/impression/files/Dockerfile`).
- **Package manager:** yarn, `--frozen-lockfile` in Docker. Commit `yarn.lock`.
- **Runtime dependencies:** `react` and `react-dom` only. No data-fetching library, no CSS framework, no date library. Everything else is a devDependency.
- **Node version:** 24 (`roles/ticker/.node-version` already contains `24`; `.envrc` already sets up fnm and puts `node_modules/.bin` on PATH).
- **Donetick base path:** `/api/v1`. Only two endpoints are used: `GET /api/v1/chores` and `POST /api/v1/chores/{id}/do`.
- **Donetick response envelope:** every response body is `{"res": ...}` on success. Error bodies are a flat object of strings, e.g. `{"error": "..."}`.
- **Donetick swarm DNS:** `donetick_donetick:2021` on the `traefik_traefik` overlay network. Both verified against the running swarm on 2026-08-15.
- **Every fetch uses `redirect: 'manual'`.** An `opaqueredirect` response means the forward-auth session expired. This is not optional — without it an expired session is indistinguishable from a network failure.
- **Completion is never optimistic.** A row crosses off only after the API returns 2xx.
- **No automatic refresh.** No polling, no refetch-on-focus, no SSE. Refresh happens only when the user presses the Refresh button.
- **Overdue means strictly past due:** `isActive && nextDueDate && new Date(nextDueDate) < now`.
- **Sort order:** by `priority` (1 = highest … 4 = lowest, `0` = unset sorts **last**), then most-overdue-first within each group.
- **All date logic takes `now` as an explicit parameter.** No test may depend on the wall clock.
- **Ansible tag:** `ticker`. Deploy with `task deploy --tags ticker`.

```ts
import type { Chore } from '../types';

const MINUTE = 60 * 1000;
const HOUR = 60 * MINUTE;
const DAY = 24 * HOUR;

function dueTime(chore: Chore): number {
    if (!chore.nextDueDate) {
        return Number.NaN;
    }
    return new Date(chore.nextDueDate).getTime();
}

export function filterOverdue(chores: Chore[], now: Date): Chore[] {
    return chores.filter((chore) => {
        if (!chore.isActive) {
            return false;
        }
        const due = dueTime(chore);
        return Number.isFinite(due) && due < now.getTime();
    });
}

// Donetick uses 1 (highest) through 4 (lowest); 0 means no priority set,
// which belongs at the bottom of the list rather than the top.
function priorityRank(priority: number): number {
    return priority === 0 ? Number.MAX_SAFE_INTEGER : priority;
}

export function sortChores(chores: Chore[]): Chore[] {
    return [...chores].sort((a, b) => {
        const byPriority = priorityRank(a.priority) - priorityRank(b.priority);
        if (byPriority !== 0) {
            return byPriority;
        }
        return dueTime(a) - dueTime(b);
    });
}

function plural(count: number, unit: string): string {
    return `${count} ${unit}${count === 1 ? '' : 's'} ago`;
}

export function formatOverdue(nextDueDate: string, now: Date): string {
    const elapsed = now.getTime() - new Date(nextDueDate).getTime();

    if (elapsed < HOUR) {
        return plural(Math.max(1, Math.floor(elapsed / MINUTE)), 'minute');
    }
    if (elapsed < DAY) {
        return plural(Math.floor(elapsed / HOUR), 'hour');
    }
    if (elapsed < 60 * DAY) {
        return plural(Math.floor(elapsed / DAY), 'day');
    }
    return plural(Math.floor(elapsed / (30 * DAY)), 'month');
}

export function overdueChores(chores: Chore[], now: Date): Chore[] {
    return sortChores(filterOverdue(chores, now));
}
```

// The forward-auth session lapsed. Traefik answered with a 307 toward the
// OIDC provider instead of proxying to Donetick. Recovering needs a
// top-level navigation, so this is not retryable in the background.
export class SessionExpiredError extends Error {
    constructor() {
        super('Your session expired. Reload to sign in again.');
        this.name = 'SessionExpiredError';
    }
}

// fetch rejected outright: no route to the server, DNS failure, VPN down.
export class NetworkError extends Error {
    constructor() {
        super("Can't reach the server.");
        this.name = 'NetworkError';
    }
}

// Donetick answered with a non-2xx status and (usually) a message.
export class ApiError extends Error {
    status: number;

    constructor(status: number, message: string) {
        super(message);
        this.name = 'ApiError';
        this.status = status;
    }
}
```

import { ApiError, NetworkError, SessionExpiredError } from '../lib/errors';
import type { Chore } from '../types';

const BASE = '/api/v1';

async function errorMessage(response: Response): Promise<string> {
    try {
        const body: unknown = await response.json();
        if (body && typeof body === 'object') {
            for (const value of Object.values(body as Record<string, unknown>)) {
                if (typeof value === 'string' && value.length > 0) {
                    return value;
                }
            }
        }
    } catch {
        // Body was not JSON. Fall through to the generic message.
    }
    return `Request failed (${response.status})`;
}

async function request<T>(path: string, init: RequestInit = {}): Promise<T> {
    let response: Response;

    try {
        response = await fetch(`${BASE}${path}`, {
            ...init,
            redirect: 'manual',
            headers: { 'Content-Type': 'application/json', ...init.headers },
        });
    } catch {
        // fetch only rejects for transport-level failures.
        throw new NetworkError();
    }

    // With redirect:'manual' the browser stops at a 3xx and hands back an
    // opaque response. Nothing under /api/* redirects except forward-auth,
    // so this unambiguously means the session expired.
    if (response.type === 'opaqueredirect' || response.status === 0) {
        throw new SessionExpiredError();
    }

    if (!response.ok) {
        throw new ApiError(response.status, await errorMessage(response));
    }

    return (await response.json()) as T;
}

export async function getChores(): Promise<Chore[]> {
    const body = await request<{ res?: Chore[] }>('/chores');
    return body.res ?? [];
}

export async function completeChore(id: number): Promise<void> {
    await request(`/chores/${id}/do`, { method: 'POST', body: '{}' });
}
```

```ts
import { useCallback, useEffect, useState } from 'react';
import { completeChore, getChores } from '../api/donetick';
import { overdueChores } from '../lib/chores';
import { SessionExpiredError } from '../lib/errors';
import type { Chore, RowStatus } from '../types';

const defaultClock = () => new Date();

export function useChores(now: () => Date = defaultClock) {
    const [chores, setChores] = useState<Chore[]>([]);
    const [rowStatus, setRowStatus] = useState<Record<number, RowStatus>>({});
    const [rowError, setRowError] = useState<Record<number, string>>({});
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState<Error | null>(null);

    const refresh = useCallback(async () => {
        setLoading(true);
        setError(null);
        setRowStatus({});
        setRowError({});

        try {
            const fetched = await getChores();
            setChores(overdueChores(fetched, now()));
        } catch (caught) {
            setError(caught as Error);
        } finally {
            setLoading(false);
        }
    }, [now]);

    useEffect(() => {
        void refresh();
        // Deliberately no focus listener and no interval: refresh is manual only.
    }, [refresh]);

    const complete = useCallback(async (id: number) => {
        setRowStatus((current) => ({ ...current, [id]: 'pending' }));
        setRowError((current) => {
            const next = { ...current };
            delete next[id];
            return next;
        });

        try {
            await completeChore(id);
            setRowStatus((current) => ({ ...current, [id]: 'done' }));
        } catch (caught) {
            // A lapsed session is not a problem with this row — it blocks
            // everything, so it belongs in the global banner.
            if (caught instanceof SessionExpiredError) {
                setError(caught);
                setRowStatus((current) => ({ ...current, [id]: 'idle' }));
                return;
            }
            setRowStatus((current) => ({ ...current, [id]: 'error' }));
            setRowError((current) => ({ ...current, [id]: (caught as Error).message }));
        }
    }, []);

    return { chores, rowStatus, rowError, loading, error, refresh, complete };
}
```

### Task 7: Docker image and nginx proxy

Packages the built app behind nginx and injects the API key server-side. Verified locally before any deployment.

**Files:**
- Create: `roles/ticker/Dockerfile`
- Create: `roles/ticker/nginx/default.conf.template`

**Interfaces:**
- Consumes: `yarn build` producing `dist/` (Task 1).
- Produces: an image serving the SPA on port 80 and proxying `/api/*` to `${DONETICK_URL}` with a `secretkey` header. Task 8 deploys it and supplies `DONETICK_API_KEY` and `DONETICK_URL`.

- [ ] **Step 1: Write the nginx template**

Create `roles/ticker/nginx/default.conf.template`:

```
server {
    listen       80 default_server;
    listen  [::]:80 default_server;

    location /api/ {
        proxy_set_header secretkey ${DONETICK_API_KEY};
        proxy_set_header Host $host;
        proxy_http_version 1.1;
        proxy_pass ${DONETICK_URL}/api/;
    }

    location / {
        root /usr/share/nginx/html;
        try_files $uri /index.html;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }
}
```

nginx's stock entrypoint runs `envsubst` over `/etc/nginx/templates/*.template` into `/etc/nginx/conf.d/` at container start, which is what turns `${DONETICK_API_KEY}` and `${DONETICK_URL}` into real values. `$host` is an nginx runtime variable, not a shell one — the entrypoint's `envsubst` only substitutes variables it is told about, and the default `NGINX_ENVSUBST_FILTER` is empty, meaning *all* environment variables are candidates. `$host` is safe because it is not an environment variable, but if a future edit introduces an nginx variable that collides with an env var name, set `NGINX_ENVSUBST_FILTER=DONETICK_` in the service environment to scope substitution.
